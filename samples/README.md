# Synthetic samples

`simulated-idle.jsonl` is a portable redacted export from the real simulator/worker/recorder path. `simulated-idle.csv` contains separately stored decoded base-unit readings. Neither file contains measured vehicle data.

Generated `sessions/` journals and SQLite indexes stay local and are excluded from Git. Run `scripts/generate_demo.py` to recreate them, then use `--data-dir samples/sessions` to list them directly. The portable JSONL is included in the repository and can be imported through Sessions → Open JSONL replay without generating anything.

Dashboard/raw screenshots and UI validation JSON are generated by `scripts/verify_ui.py`. Sample preview data reside inside this OneDrive project; normal app recordings default to LocalAppData.
