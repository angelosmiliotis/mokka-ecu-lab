# v0.2.10 evidence review and unresolved definitions

Private originals and every supplied auxiliary table were independently checked outside Git. Original ZIP CRC/member hashes and the original report JSON were verified; numeric rows were re-derived from original packets using the reviewed definitions, field flags and current range configuration. Advertised support, actual replies, implemented definition, accepted payload layout and physical accuracy remain different facts. Actual vehicle counts, ranges, bytes, timestamps, identifiers and plots are deliberately excluded from this public document.

| Area | Software/research result | Remaining boundary |
|---|---|---|
| Existing standard definitions | Reviewed per-PID framing, lengths, field flags, units, current selectors and numerical agreement | Generic decoding agreement does not certify independent physical calibration |
| 018C | Correctly framed alternative lengths remain observable offline; strict synthetic 15-byte regressions reject numeric decoding | No verified applicable primary 15-byte definition; no padding, truncation or guessed oxygen/lambda values |
| 0101 | Historical readiness definition depends on ignition-specific supported/complete semantics | Complete readiness implementation and current positive evidence deferred; no live request |
| 019D | Later authoritative definition and vehicle applicability still required | No verified exact layout/scaling/flags; no live request |
| VGT / pedal / throttle / EGR | Separate standard meanings and per-field availability; bounded critical-subset profile improves opportunity for context sampling | Sparse/asynchronous observations cannot prove turbo lag, Sport response or a component fault |
| Range configuration | Current same-ECU 014F/0150 determines MAP/MAF interpretation when advertised | Historical recordings without selectors cannot establish physical scaling; originals preserved |
| SCR / NOx / reagent / PM | Current inducement, historical counters, quantized tank values and PM-sensor status remain distinct | Sensor placement/physical accuracy not independently confirmed; PM-sensor regeneration is not DPF regeneration |
| Six-byte 017A | All raw bytes, observed quantization, age-gated motion/thermal groups and descriptive correlations retained privately | No verified pressure units, soot/ash mass, DPF regeneration or health conclusion |

The v0.2.9 functional definitions remain based on **SAE J1979-DA OCT2011**. Primary [SAE 2019 edition metadata](https://saemobilus.sae.org/standards/j1979da_201905-j1979-da-digital-annex-e-e-diagnostic-test-modes) and [later edition metadata](https://saemobilus.sae.org/standards/j1979da_202510-j1979-da-digital-annex-e-e-diagnostic-test-modes) establish that later revisions exist; they do not supply an accessible exact vehicle-applicable 15-byte table in this review. A catalogue entry or third-party PID list cannot justify a new decoder. No copyrighted tables/PDFs or private packets are distributed.

Raw first-word endian/signedness alternatives and flow/load/temperature explanations remain competing hypotheses. Pearson/Spearman correlations use actual prior samples with age limits, preserve missing context and separate motion groups. Coolant bins are descriptive labels, not validated warm-engine/health criteria. Serial dependence and non-simultaneous samples prohibit causal conclusions.

The fixed speed/RPM/MAP/MAF benchmark measures communication inside an approved ceiling, not ECU capacity. Separate requests at different user-selected rates preserve run identities, original journals and unchanged PID mix. Thermal state, exact ECU identity and driving load can differ; no drive trace is merged with a benchmark. Higher-than-four testing remains a separately authorized future phase.
