# Offline sensor research · v0.2.8

This is a research record, not a live protocol extension. Exact ECU hardware/software/calibration remain unknown from the permitted generic observations; a CAN address or a shared manufacturer/family name cannot establish DID applicability. [Structured records](../mokka_ecu_lab/research/roadmap.py) include sources, applicability, units, formula/length where known, revision, validation status, contradictions and risk. They never feed the transmit allowlist or numeric decoder loader.

## What current sources establish

The [SAE J1979-DA July 2026 catalog](https://saemobilus.sae.org/standards/j1979da_202607-j1979-da-digital-annex-e-e-diagnostic-test-modes) confirms a later digital-annex revision exists. Its public metadata is not a reviewed full byte definition. Existing code uses the documented OCT2011 definitions; no later-edition six-byte `017A` formula was verified in this review. A licensed applicable definition and independent reference are still required.

[Bosch differential-pressure sensor documentation](https://www.bosch-mobility.com/en/solutions/sensors/differential-pressure-sensor/) describes pressure-drop sensing in aftertreatment and other applications with different variants. This supports a physical validation approach, not identification of an unknown Mode 01 layout. [Sappok and Wong's ash study](https://saemobilus.sae.org/articles/ash-effects-diesel-particulate-filter-pressure-drop-sensitivity-soot-implications-regeneration-frequency-dpf-control-2010-01-0811) shows why ash changes pressure sensitivity. Our inference is that one uncalibrated raw integer, without flow/temperature/model/reference, cannot uniquely identify soot or ash mass.

[Bosch NOx sensor documentation](https://www.bosch-mobility.com/en/solutions/sensors/nox-sensor/) describes NOx measurement in SCR control/monitoring. It does not establish physical upstream/downstream placement from a generic bank/slot name, nor conversion efficiency from one available sensor.

The manufacturer's [Opel technical-documentation offer](https://fca.servicebox-parts.com/cgv/OV/DOCTECH_ctc_en.pdf) and [DiagBoxCloud prerequisites](https://public.servicebox-parts.com/cgv/OV/A2DR_ctc_en.pdf) identify a manufacturer-supported documentation/diagnostic route. No registration, purchase, VIN submission, tool installation or diagnostic session was performed. Same-calibration documented data and an independently authorized reference would be needed before assigning physical units to a proprietary signal.

## Target records and contradictions

| Target | Current status / missing evidence |
|---|---|
| Six-byte `017A` | RAW only. The seven-byte OCT2011 numeric definition cannot be padded, shifted or applied by guessed scaling. Exact byte roles, signedness, units, variant and calibration are unverified. |
| Regeneration active `018B` | Existing standard definition remains gated by current ECU/field support. Unsupported/no sample means no regen observation. RPM, temperatures, raw pressure-like variation or average counters do not replace that observation. |
| Soot / ash mass | No applicable PID/DID/formula established. Flow, thermal state, sensor zero and ash distribution confound pressure-based interpretation. |
| Distance/time since last regen | No validated last-event source established. Standard averages, engine runtime and SCR historical distance do not substitute. |
| Exhaust temperatures `0178/0179/017C` | Existing generic definitions; actual availability is per ECU and per field. No unsupported probing. |
| AdBlue quality / pressure | No applicable signal/formula established. `0185` level/demand/average fields are different quantities. |
| NOx before/after SCR | Log every genuinely supported `0183` slot. Physical location and independent matched references remain required. |
| Legacy `22 D525/D526/D52F/D532` | Speculative offline leads only. No authoritative same-calibration mapping, units or frame length was verified. Shared ECU-family/community labels are not proof. Live requests remain prohibited. |

The [DashLogic product manufacturer's historical PID listing](https://www.dashlogic.com/docs/technical/obdii_pids) provides additional standard leads: throttle `0111`, relative pedal `015A`, absolute rail pressure `0159`. The structured records retain its stated units/length/formula as a vendor reference with unspecified applicable SAE edition. These PIDs are **outside the v0.2.8 allowlist**, have no current ECU support evidence here, and are not queried. Throttle on a diesel is not necessarily driver demand; pedal/gear/commanded boost and adequate comparable-event sampling would still be needed for turbo-response research.

## Falsifiable validation requirements

For each future decoder: obtain an authoritative revision and exact-ECU/calibration applicability; verify full framing, service/identifier and field flags; document units, signedness, sentinels, frame length and contradictions; pair multiple stationary and ordinary operating samples with an independent reference and explicit timing/uncertainty; test hypotheses against unseen data. Reject or retain UNKNOWN when evidence is insufficient. No health or regeneration conclusion follows from a single snapshot or serial correlation.

Any future new live standard/OEM scope requires separate explicit authorization and independently audited policy/decoder changes. v0.2.8 adds no Mode 22, UDS, security access, identification, reset, coding, actuation or forced regeneration command. Real evidence and derived reports remain private; public tests use constructed data only.
