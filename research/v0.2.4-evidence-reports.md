# v0.2.4 evidence fidelity and private offline reports

This software-only release starts from v0.2.3. No vehicle connection, request, permission, numeric SAE formula or physical verification is added. B115/B102 sources remain documented in [v0.2.3 source review](v0.2.3-offline-engine.md). The decoder identifier remains `SAE-OCT2011-v0.2.3` because formulas are unchanged; `analyzer_version` identifies the updated offline release.

## Independent evidence dimensions

| Field | Meaning |
|---|---|
| `support`, `raw_bitmap_support` | SUPPORTED / UNSUPPORTED / UNKNOWN from an ordered original bitmap chain in the same session, ECU, mode and source. Existing `support` meaning is preserved. |
| `recorded_discovery_support` | SUPPORTED / UNSUPPORTED / UNKNOWN / CONFLICT from checksum-verified pid-support and Discovery rows. Recorded snapshot, never independently raw-verified. |
| `positive_response_count` | Complete positive replies, including unknown numeric layouts; excludes negatives and parser errors. |
| `observation_state` | VEHICLE_OBSERVED / SIMULATED_OBSERVED / UNKNOWN_SOURCE_OBSERVED when positive replies exist; NOT_OBSERVED otherwise. No decoder/health certification. |
| `evidence_explanation` | Provenance gaps and disagreements. Raw UNKNOWN plus supported snapshot is incomplete evidence, not a contradiction. |

Snapshots are scoped by ECU and stored mode/source metadata. An unscoped snapshot with multiple source groups for the same ECU stays ambiguous. Conflicting snapshots yield CONFLICT. Raw/snapshot disagreements remain explicit. Snapshot UNSUPPORTED concerns a standard PID, not every possible OEM equivalent signal.

## Bitmap and framing states

Complete positive bitmap pages 00/20/40/60/80/A0/C0/E0 require four data bytes. BITMAP_VALID_ANCHORED means predecessors and continuation were already observed. BITMAP_VALID_UNANCHORED / MISSING_PREDECESSOR_EVIDENCE means valid four-byte payload with missing chain provenance: bits cannot infer support and layout errors do not increase. BITMAP_INVALID_LENGTH is a true layout error; ISO-TP errors and negatives have separate counts.

BITMAP_CHAIN_CONFLICT means conflicting original page values or contradiction of the parent continuation bit. That page/parent and descendants are quarantined. BITMAP_MIXED_EVIDENCE preserves multiple categories/counts. Later predecessors do not retroactively anchor earlier replies. Legacy eleven-file bundles without raw-observations.json still supply the complete original raw journal; missing sidecar is a format note.

## GUI workflow and private exports

1. Open Research → Offline evidence analyzer → Import local Research Bundles. Select 1–16 existing ZIPs. Checksum/member/path/decompressed-size/journal/group/preview limits remain enforced; originals are unchanged.
2. Choose session/ECU/mode/source. Compatibility displays separate snapshot/raw support, positive samples, framing, layout, observation and notes. Scroll/resize columns; select a row for full details. Colors do not substitute for evidence states.
3. SCR / AdBlue summary shows inducement only at the latest complete reply's acquisition time when its documented 13-byte layout is valid. No reply or invalid latest layout means UNAVAILABLE, never inactive. Current reasons, latched history and five unsigned kilometre counters remain separate; counter warnings are explicit.
4. Tank-level counts/range are quantized observations, not consumed volume. Static/nonzero warning time is not a current fault. NOx counts/availability are explicit; one sample is not a trend. Independent verification stays UNVERIFIED.
5. Export private research report accepts a fresh HTML or JSON name. HTML creates a sibling full-evidence JSON. HTML covers the selected group; JSON retains all analyzed groups/provenance. Compact HTML excludes identity fields and raw timelines. The unchecked Include private raw preview and timestamps option explicitly enables a bounded detailed preview. There are no external scripts/fonts/images/CDN/analytics/automatic requests; imported text is escaped and restrictive CSP blocks external resources.
6. Open HTML locally in a browser. Review both files before sharing; JSON is private even when HTML is compact. Existing reports/imports cannot be overwritten by default. Each output file is atomic; a rare second-file destination race may leave the first completed file, never a partially written file.

The offline Next recording checklist sends no commands. It recommends recording before Connect, stationary Discovery, the observed ECU, manual supported 017A RAW / documented 0188 or RAW / 0183 / 0185 / RPM / MAF / speed, and Finish/Disconnect after parking. The driver must not operate the laptop while driving. No unsupported selection, automatic scan, increased rate or regeneration is enabled.

## Headless analyzer

```powershell
.\.venv\Scripts\python.exe -m mokka_ecu_lab --analyze-bundles "C:\private\old-bundle.zip" --research-output "C:\private\new-analysis.json" --research-html "C:\private\new-report.html"
```

The executable accepts the same arguments and starts no GUI/transport. --research-detailed-report explicitly includes raw preview/timestamps in HTML. Fresh filenames are required. Without --research-html only full private JSON is saved.

## Schema and migration

Analysis schema_version stays **1** with additive analysis_revision=2. Existing keys remain; support is always raw-only. vehicle_evidence now correctly indicates NOT_OBSERVED for zero samples; use explicit observation_state going forward. recorded_support remains a list; the new scalar distinguishes conflicts. New fields cover analyzer version, bitmap counts, layout/frame states, explanations and source-specific SCR aggregates. Journals, bundles and catalog schema are unchanged.

Open saved analysis reads schema-1 JSON without rewriting it and labels SAVED_ANALYSIS_NOT_REVALIDATED. Older reports gain observation/support fields from retained aggregates. Their original support/layout-error counts are preserved; bitmap rows show LEGACY_ANALYSIS_REQUIRES_REIMPORT. Re-import the original ZIP to fix old bitmap classifications and recover complete AdBlue/NOx aggregates. Legacy SCR preview bytes use the code-owned decoder, never stored formulas. Saved JSON cannot revalidate original checksums or promote hypotheses.

Six-byte 017A remains RAW with unknown numeric meaning: no signed-pressure assumption, padding/shifting, blockage or DPF-condition inference. Exact ECU HW/SW/calibration and independent physical verification remain unknown. OEM D525/D526/D52F/D532 stay offline candidates. Only constructed tests/software summaries are distributed; private bundles, route statistics, reports and copyrighted SAE pages stay outside GitHub/releases. This release requires no new road test.
