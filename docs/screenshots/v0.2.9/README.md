# v0.2.9 synthetic Windows verification

These are actual native Qt screenshots generated with simulation only. No hardware or private vehicle bundle was used. Visible dates, sample identifiers, bytes and paths belong to synthetic validation runs.

The expanded scenario deliberately uses a different 38-identifier bitmap set, response address and RAW payload family from private input. It schedules 36 eligible definitions, not 38 decoded physical sensors. One deliberate six-byte numeric 017A layout mismatch remains separate from subsequent successful RAW-only polling. The benchmark is fixed at 2 req/s; none of these pictures proves vehicle capacity or a physical DPF decoder.

The simple three-action workflow, RAW READY, export/disconnect, field catalog, original 13-PID case, advanced benchmark and offline reports were inspected across 100/125/150% Qt pixel ratios and four resolutions. The portable results are in [the synthetic validation summary](../../../samples/v0.2.9-validation.json). Actual private captures and reports are excluded.
